# Quick tour

The window has a **title bar** across the top and a **sidebar** down the left. The sidebar groups the pages by how you will use them.

| Group | Page | What it is for |
|---|---|---|
| Discover | [Home](/guide/home) | Ask any free AI, see status cards, open your favorites |
| | [AI Tools](/guide/ai-tools) | Compare 29 free-tier AI tools |
| | [Bookmarks](/guide/bookmarks) | 270 free web tools, and your own |
| Developer | [Runtimes](/guide/runtimes) | See which local AI servers are running |
| | [Configs and limits](/guide/configs-and-limits) | Config snippets for editors and agents, and a free-tier rate-limit table |
| | [Setup](/guide/setup) | One-click install of Ollama, Gemini CLI and Qwen Code |
| Secure | [Key Vault](/guide/key-vault) | Store and test your API keys |
| | [Settings](/guide/settings-and-backups) | Themes, preferences, backup and restore |

The number keys `1` to `8` jump to these pages in this order. See all [keyboard shortcuts](/guide/shortcuts).

## The title bar

From left to right: the logo (click it for Home), the page title, a search box, a button that adds a tool or bookmark on the pages where that makes sense, a light/dark toggle, the **Help** menu, and the window buttons. LocalMind draws its own window frame, so drag the empty part of the title bar to move the window and double-click it to maximize.

The search box opens the **command palette** (`Ctrl+K`, or `Cmd+K` on macOS). Type to find any page, tool or bookmark, or an action such as opening Settings.

## The Help menu

The `?` icon in the title bar opens:

- **Keyboard Shortcuts**: the cheat sheet (also `?` on the keyboard).
- **Welcome and Quick Start**: the first-run overview, again.
- **About LocalMind**: your version, a short privacy statement, and a **What's New** list of every release.
- **Documentation**: opens this site in your browser.
- **Report a Problem**: saves a diagnostics file you can attach to a bug report. See [Troubleshooting](/guide/troubleshooting#report-a-problem).

## A good first five minutes

1. On **Home**, type a question and press Enter. It opens in the AI shown next to the box.
2. Open **AI Tools** and tick *No credit card* in the filter rail to see what is free with no card.
3. Star a few tools. They appear on Home under **Favorites**.
4. If you use a coding assistant, open **Key Vault**, add a key from a free provider, and press **Test**.
5. Open **Settings** and pick a theme you like.

## Collapsing the sidebar

Click **Collapse** at the bottom of the sidebar to show icons only. LocalMind remembers the choice. On a narrow window, the sidebar becomes a bar along the bottom.
