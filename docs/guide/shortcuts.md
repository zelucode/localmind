# Keyboard shortcuts

Press `?` anywhere in the app to see this list. Single-letter shortcuts are ignored while you are typing in a text field. On macOS, use `Cmd` where this page says `Ctrl`.

## Navigation

| Keys | Action |
|---|---|
| `Ctrl+K` | Open the command palette: find pages, tools, bookmarks and actions |
| `1` | Home |
| `2` | AI Tools |
| `3` | Bookmarks |
| `4` | Runtimes |
| `5` | Configs and limits |
| `6` | Setup |
| `7` | Key Vault |
| `8` | Settings |
| `/` | Focus the search box on the current page |

## Shortcuts to tools

| Keys | Action |
|---|---|
| `k` | Go to the Key Vault |
| `c` | Go to the Config Exporter |
| `l` | Go to the Rate-Limit Matrix |
| `b` | Add a custom tool or bookmark |

## Everywhere

| Keys | Action |
|---|---|
| `?` | Show the shortcut sheet |
| `t` | Switch between light and dark |
| `Esc` | Close the topmost dialog or menu |

## During startup

The loading screen can be skipped with `Space`, `Enter`, `Esc`, a click, or the **Skip** button.
